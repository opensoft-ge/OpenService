Operation and inputs

Use an array of up to 20 fields. Each has key, label, type, required and choices. Types: string, choice, boolean, date or integer. Only choice fields have nonempty choices. Example: [{"key":"title","label":"Title","type":"string","required":true,"choices":[]}]. Values are sent as JSON strings; paths and headers are fixed.
