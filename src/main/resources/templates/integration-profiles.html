Gateway request and signing contract

Send POST with application/json to the path below, using the gateway's table-scoped write API key as a Bearer credential.

The body is a JSON object with only fields, containing allowed string values. Include exactly one X-OpenService-Event, X-OpenService-Timestamp and X-OpenService-Signature header. Event identity may contain letters, digits, dot, underscore, colon, at sign, slash and hyphen, up to160 characters.

Timestamp is canonical epoch seconds within300 seconds of server time. Signature is lowercase hexadecimal HMAC-SHA256 with the literal UTF8 signing secret. Sign timestamp, newline, profile identity, newline, event identity, newline, followed by the exact raw request-body bytes. Maximum body size is16KB.

For a retry, keep event identity and field content, and sign again with a fresh timestamp. Reusing an identity with changed content fails. Provider-specific webhook formats require an adapter.
