Maintenance and blackout windows

Maintenance windows allow work; blackout windows prevent it. Rules use the current calendar, including its timezone and holiday exclusions. Changes apply immediately to future conflict checks.

Scheduling policy

A proposed interval must fit entirely inside at least one active maintenance calendar when maintenance rules exist. Any blackout overlap is a conflict. With no active maintenance rule, only blackouts and other reservations restrict this item.
