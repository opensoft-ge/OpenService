Account details

Issue table-scoped keys for an active, non-administrator API-only account. Each key permits one table through the Table API and retains the account’s record and field restrictions. Keys are read-only by default. Agents can also receive create/update keys; deletion and other endpoints remain unavailable. Keys expire after 1–90 days. Rotation immediately replaces the old secret without changing its scope or expiry; update your integration with the new secret. Suspend a key to temporarily deny it; resuming preserves its secret and still requires valid expiry and account access. Account access changes invalidate existing keys.
