Acceptance: delegation must not confer unrelated record access, chain authority or survive revocation. Next: delivery cancellation/retention and approval-request foundations. A stale account-directory help sentence was also noted for a later identity/UI correction; it does not change current enforcement.

Round 2 reviewed the full accumulated query, projection, UI, authorization, fixture and documentation changes; no further runtime defect was found. The prematurely started full run was stopped, then the repaired browser test passed. Targeted SQLite/PostgreSQL and browser checks pass; the clean full gate passed.

Explicit PURGE confirmation, transactional audit, no automatic cleanup. The grace period is since link expiry, not terminal transition. Preview is an estimate, recalculated at apply.
